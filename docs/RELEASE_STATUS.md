# V0.2.1 公开预览发行状态

本版补全订阅与实际额度窗口的适配。GitHub 独立构建 [40171708791](https://github.com/Dddysun/Codex-Mission-Manager/actions/runs/40171708791) 已通过；公开包已下载并重新完成只读完整性和运行环境检查。

## 本轮更新

- V0.2.1 build 5 将正常采集间隔调整为 30 秒，临近额度阈值或有待执行预约时调整为 10 秒；界面仍每 5 秒读取缓存。轮间等待在采集与控制处理结束后开始，异常退避不变。
- 移除固定要求五小时主窗口的条件；按实际时长识别五小时、周及其他窗口，支持仅周额度与窗口位置交换。
- Free、Go、Plus、Pro、Business、Enterprise、Edu 及未知套餐按服务实际数据处理，不根据套餐名称猜测额度或倍数。
- primary 与 secondary 明确为空且服务明确允许时，显示无固定窗口的使用许可；缺失、非法或过期数据保持未知，不视为无限。
- 暂停、恢复、即时执行和一次性预约统一校验实际窗口与服务许可。可选许可字段出现错误类型时禁止发送。
- 预约显示真实目标窗口及刷新时间。没有固定窗口时不创建新的窗口预约，仍可取消旧预约，并按条件使用立刻执行。
- 旧版五小时预约不被重新解释为周预约；窗口变化时需要重新确认。用户显式重新保存后绑定当前实际窗口。
- 账号身份与套餐分离，同一账号升级订阅不被误判为换账号；精确匹配的 V0.2 本机记录可原子迁移，保留许可、人工保持、指令、预约及请求标识。
- 保留 V0.2 的中英文、跟随系统/深浅外观、原生菜单栏、逐项回执与兼容检查。

完整规则见 [订阅适配说明](SUBSCRIPTION_ADAPTATION.md)。

## 验证范围

本轮测试使用隔离账本和模拟服务响应，不发送真实聊天指令。涵盖订阅名称、缺失五小时窗口、周窗口独立返回、任意有效窗口时长、窗口换位、显式无窗口许可、未知/错误数据、恢复规则、预约重新确认，以及升级/换账号隔离。

本机已通过190项后端测试（含39项订阅专项）、4项打包宿主测试、原生控制契约与 JavaScript 检查。四种订阅状态分别完成主窗口及菜单栏原生渲染，共8个视图。DMG 只读挂载、代码签名完整性和内置运行环境检查通过；结果记录于 `validation.json`。签名完整性不等于 Developer ID 签名或 Apple 公证。各套餐的模拟响应测试不等于已完成各真实账号的长期实测。

公开发行包已完成本机替换安装（0.2.1 / build 5），升级前后的自动控制偏好与预约记录一致。首次启动曾因“文稿”文件夹访问提示待处理而初始化超时；用户自行处理系统提示后，应用正常重开。2026-10-25 的应用后台接口复验已通过：后台运行、额度数据新鲜、自动控制启用、客户端 build 21828 匹配，聊天目录和执行阶段可读取，任务错误为零。同账号旧记录迁移已实际发生，许可及人工保持保留；后续用户主动修改许可或重新预约的记录另行区分。

本轮还确认一条由用户自行预约的恢复后指令在 2026-10-25 10:11（UTC+04）真实送达原会话：账本只有一次发送确认，与会话实际收到的消息一致。该观察没有额外发送测试指令，不代表低额度自动暂停、默认续接、即时按钮、全部套餐或锁屏/合盖发送路径已完成验收。

连接恢复后，只读观察了三轮正常状态下的缓存发布：从轮次开始至状态文件发布分别为 22.05、8.23、22.17 秒，均值 17.48 秒；当时目录为 30 个聊天、任务运行状态为 4 份，三轮没有记录到控制动作。该指标包含任务检查，不含之后的通知和轮间等待；仅为单机短时样本，不能作为长期均值或性能承诺。观察器只读取已有缓存及账本，没有额外调用客户端。

本次 build 5 已从公开发行页下载并校验摘要，安装后确认新后台采样正常，运行配置与包内默认值均为 30/10 秒，界面刷新保持 5 秒；完整预约、请求记录及控制许可已核对保留。上文三轮耗时观察来自 build 4、60/15 秒轮间等待设置，不属于 build 5 的新性能测量。

## 运行与发行边界

- Apple Silicon，macOS 14+；安装并登录兼容桌面客户端。目前兼容配置覆盖 build 20770 与 21828。
- 安装包包含原生 SwiftUI/AppKit 窗口、后端和 CPython，日常使用不需要另装 Python、Node 或 Homebrew。
- 无 Developer ID 发行签名与 Apple 公证，其他电脑可能被 macOS 阻止打开。管理员合盖辅助服务保持不可用。
- 21828 的只读连接及用户一次性预约发送已有验证；低额度自动暂停、默认续接、即时按钮和自然额度重置完整流程仍需独立实机验收。
- 普通 ChatGPT/云端聊天目前没有自动执行通道；安装包不含个人云端聊天目录。自动发现与私有桌面 IPC 不是本版修改范围。
- 不提供多账号同时登录或自动更新；不自动购买额度、消耗重置权益或改变付费方式。
