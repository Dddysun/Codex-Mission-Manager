# V0.2.1 公开预览发行状态

本版补全订阅与实际额度窗口的适配。最终安装包与独立构建结果以本页和 `validation.json` 的发布记录为准。

## 本轮更新

- 移除固定要求五小时主窗口的条件；按实际时长识别五小时、周及其他窗口，支持仅周额度与窗口位置交换。
- Free、Go、Plus、Pro、Business、Enterprise、Edu 及未知套餐按服务实际数据处理，不根据套餐名称猜测额度或倍数。
- primary 与 secondary 明确为空且服务明确允许时，显示无固定窗口的使用许可；缺失、非法或过期数据保持未知，不视为无限。
- 暂停、恢复、即时执行和一次性预约统一校验实际窗口与服务许可。可选许可字段出现错误类型时禁止发送。
- 预约显示真实目标窗口及刷新时间。没有固定窗口时不创建新的窗口预约，仍可取消旧预约，并按条件使用立刻执行。
- 旧版五小时预约不被重新解释为周预约；窗口变化时需要重新确认。用户显式重新保存后绑定当前实际窗口。
- 账号身份与套餐分离，同一账号升级订阅不被误判为换账号；精确匹配的 V0.2 本机记录可原子迁移，保留许可、人工保持、指令、预约及请求标识。
- 保留 V0.2 的中英文、跟随系统/深浅外观、原生菜单栏、逐项回执与兼容检查。

完整规则见 [订阅适配说明](SUBSCRIPTION_ADAPTATION.md)。

## 验证范围

本轮测试使用隔离账本和模拟服务响应，不发送真实聊天指令。涵盖订阅名称、缺失五小时窗口、周窗口独立返回、任意有效窗口时长、窗口换位、显式无窗口许可、未知/错误数据、恢复规则、预约重新确认，以及升级/换账号隔离。

本机已通过190项后端测试（含39项订阅专项）、4项打包宿主测试、原生控制契约与 JavaScript 检查。四种订阅状态分别完成主窗口及菜单栏原生渲染，共8个视图。DMG 只读挂载、代码签名完整性和内置运行环境检查通过；结果记录于 `validation.json`。签名完整性不等于 Developer ID 签名或 Apple 公证。各套餐的模拟响应测试不等于已完成各真实账号的长期实测。

## 运行与发行边界

- Apple Silicon，macOS 14+；安装并登录兼容桌面客户端。目前兼容配置覆盖 build 20770 与 21828。
- 安装包包含原生 SwiftUI/AppKit 窗口、后端和 CPython，日常使用不需要另装 Python、Node 或 Homebrew。
- 无 Developer ID 发行签名与 Apple 公证，其他电脑可能被 macOS 阻止打开。管理员合盖辅助服务保持不可用。
- 21828 的只读连接与界面已有验证；真实暂停、续接、即时发送和自然额度重置流程仍需独立实机验收。
- 普通 ChatGPT/云端聊天目前没有自动执行通道；安装包不含个人云端聊天目录。自动发现、私有桌面 IPC 及刷新频率不是本版修改范围。
- 不提供多账号同时登录或自动更新；不自动购买额度、消耗重置权益或改变付费方式。
