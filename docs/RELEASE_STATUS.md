# V0.2.0 公开试用版发行状态

状态：V0.2 公开试用版。本机回归与打包验收已完成，公开安装包由 GitHub Actions 独立构建。产品范围以 [产品总蓝图](PRODUCT_BLUEPRINT_V0.1.md) 为准。此文件区分本轮更新范围、已知验证与待完成项目，不将开发完成等同于正式发行。

## 本轮更新范围

- 客户端兼容状态由前后端共享；支持 build 20770 与 21828 的兼容配置，并在每次控制前重新检查版本。
- 全局自动控制暂停时，单聊请求显示“等待全局启用”，允许取消；连接失败显示原因及重试入口，待处理请求去重。
- 权限设置改为统一滑块、状态说明和系统设置入口；新安装可选开关默认关闭，升级保留已有偏好。
- 通知滑块控制应用通知偏好；实际发送还需 macOS 授权。关闭应用通知不代表撤销系统授权。
- 新增跟随系统、浅色、深色外观，以及即时切换的简体中文和 English 界面。
- 固定菜单栏图标支持左键和右键打开面板，展示账号实际额度与订阅信息，并提供自动控制、手动暂停、主窗口、设置、语言、外观和退出入口。
- “暂停所有任务”仅处理已授权接管的执行中任务，跳过审批和输入等待；确认后保留手动保持状态，恢复全局自动控制不会隐式恢复。
- 公开界面文案移除对话口吻和内部开发说明，保留用户需要的限制、原因和处理入口。

## 兼容性证据

build 21828 已完成本机只读握手、聊天归属查询及实时快照检查，读取到的快照协议为版本 11。该结果说明只读连接可用，不代表真实暂停、续接或即时发送已通过验收。

本轮 145 项后端测试、4 项打包宿主测试、原生控制契约及 JavaScript 检查通过。主窗口、设置、菜单栏分别完成中文浅色与英文深色原生渲染，共 6 个视图；未启动真实控制后台或发送测试消息。DMG 通过只读挂载、代码签名完整性、内置 CPython、自检与无 WebKit 依赖检查。签名完整性检查不代表 Apple 发行签名或公证。

GitHub 独立构建 [40135193611](https://github.com/Dddysun/Codex-Mission-Manager/actions/runs/40135193611) 已通过，公开预览包已发布。具体资产校验值见 `validation.json` 与发行页。下载的公开 DMG 已在本机再次核验并安装；原有自动控制偏好保留，后台健康、额度数据新鲜。设置窗口的即时中英文切换和深色切换已实测，并恢复原有偏好。真实暂停与发送未用于这次界面验收。

## 当前限制

- 无 Developer ID 发行签名与 Apple 公证；其他电脑可能被 macOS 阻止打开。
- 合盖运行辅助服务暂不可用。锁屏、熄屏和无外屏合盖下的完整发送流程仍未完成实机验收。
- build 21828 尚未完成真实暂停、续接与即时发送验收，不承诺任意未来客户端版本可用。
- 普通 ChatGPT 聊天仅目录；安装包不含个人云端聊天快照，未提供持续云目录同步。
- Apple Silicon / macOS 14+；Intel 与 Windows 未构建、未验证。
- 尚无多账号同时登录及自动升级。

## 正式发行条件

正式发行仍需 Developer ID 签名、Apple 公证与完整实机验收。管理员辅助服务需可信发行身份与用户系统授权；没有这些条件时保持不可用，不将配置存在或代码构建成功展示为权限已获批。

运行数据、账号、聊天、令牌和本机账本不进入公开仓库或安装包。发布验证只记录经过脱敏的结果。
