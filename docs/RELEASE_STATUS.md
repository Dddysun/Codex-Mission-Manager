# V0.1 本机预览发行状态

这是开发预览，不是完整验收的正式发行版。产品范围以 PRODUCT_BLUEPRINT_V0.1.md 为准，下面保留实际缺口。

## 已实现

- SwiftUI / AppKit 原生主窗口及设置页；原生列表、开关、文本编辑、额度进度、账号侧栏、操作记录和回执。不使用 WebKit。
- 固定菜单栏 Logo；打开窗口、全局暂停/恢复、退出。
- 原有聊天目录、执行阶段、额度账号、自动控制、下一窗口预约、立刻执行及回执。
- 后端与精简的可重定位 CPython 运行环境随 .app 分发。
- 设置中的登录启动、通知申请与复查、系统设置入口、防空闲睡眠、客户端兼容检测。
- 原网页版正在运行时优先连接，不启动重复执行器；显式离线迁移工具拒绝覆盖现有账本。
- 合盖增强辅助服务源码：固定命令、签名身份限制、心跳租约、恢复日志、低电量及热压力保护。

## 当前不能宣称完成

- 没有 Developer ID 发行签名和 Apple 公证。仅临时签名预览；管理员合盖服务被禁用，不提供绕过系统验证的方法。
- 本机完整 GUI 交互、通知展示、登录自启动、锁屏/熄屏真实发送和无外屏合盖实机验收尚未完成。
- 当前桌面控制只适配 build 20770，属于私有兼容接口，不能宣称支持任意版本。
- ChatGPT 普通聊天仅目录；不附带个人云端聊天快照，也尚未提供持续云目录同步渠道。
- 当前没有多账号同时登录及自动升级。
- 构建产物平台为 Apple Silicon / macOS 14+；Intel 未构建、未验证。

## 验收证据

后端原有116项隔离测试及新增打包宿主测试；内置 Python、原生主程序和辅助服务提供无副作用自检。实际构建、签名校验、DMG 校验和挂载证据见 validation.json。GitHub Actions 独立重建，成功时在本仓库发布带明确预览标签的 DMG、SHA256SUMS 和构建清单。

## 正式发行的后续条件

1. 在用户 Keychain 配置 Developer ID Application 签名身份；构建时提供团队 ID 和身份名称，不将证书或密码提交仓库。
2. 正式签名后，使用已配置的 notarytool Keychain profile 提交公证，并 staple 到应用和最终 DMG。
3. 用户在应用中主动开启增强模式，批准管理员辅助服务；拒绝授权保留正常后台功能。
4. 在目标机器分别完成开盖后台、锁屏、熄屏、无外屏合盖和真实窗口恢复的发送验收。

本次打包不安装管理员服务、不改变系统电源设置，也不向真实聊天发送测试消息。
