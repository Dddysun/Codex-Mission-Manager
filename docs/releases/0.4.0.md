# V0.4.0 — TokenMax · 榨汁机

## 本次更新

- 应用更名为“榨汁机 / TokenMax”，更新图标和两平台安装包。
- 新 Logo：停用时灰色静止；启用时金色闪电呼吸、细线电弧绕杯与旋钮轻转，移除杯内漩涡。适配深色及系统减少动态效果。
- 任务页改为“来一杯 / Juice Bar”。等待、断连和错误状态以杯内专用符号区分。
- 启动操作改为“开始榨汁”，聊天开关标题改为“榨汁状态”，移除旁边重复的开关标签。
- 精简中英文提示。额度恢复记录默认显示摘要，详细依据按需展开，保留来源推断标记。
- 原有任务授权、预约、规则和历史继续保留。

## What's new

- Renamed the app **TokenMax** (榨汁机 in Chinese), with new icons and packages on both platforms.
- A gray static logo while stopped; a breathing gold bolt, fine orbiting arcs, and gentle dial motion while enabled, without the cup vortex. Dark appearance and reduced motion are supported.
- The task page is now **Juice Bar**. Waiting, disconnected, and error states use distinct symbols inside the cup.
- **Start Juicing** replaces the start action. Per-chat controls use **Juicing** without redundant switch labels.
- Shorter Chinese and English copy. Quota recovery entries show concise summaries, with evidence available on demand and inferred attribution retained.
- Existing task permissions, schedules, rules, and history are preserved.

## 升级 / Upgrade

退出旧版后安装。Mac 新应用名为 `TokenMax.app`，安装后移除已退出的旧名 `Codex Mission Manager.app`，勿同时运行。Windows 沿用原安装目录。内部数据标识保持兼容，设置和历史不迁移、不清空。

Quit the old version before installing. On Mac, install `TokenMax.app`, then remove the old-named `Codex Mission Manager.app`; do not run both. Windows retains the installation directory. Internal data identifiers remain compatible, so settings and history stay in place.
