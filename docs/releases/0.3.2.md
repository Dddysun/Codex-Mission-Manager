# V0.3.2 public preview / 公开预览

This update fixes clipped text in Windows input fields, especially numeric values on the Rules page. The cause was duplicated spacing in the application template combined with a fixed field height. This update does not require changing Windows display settings or installing additional fonts. Mac UI behavior and the existing quota-control rules remain unchanged.

本次修复 Windows 输入框中文字下沿被裁切的问题，重点是运行规则页的数值。原因是应用模板重复计算内边距，并为输入框设置固定高度；无需通过修改 Windows 显示设置或安装字体解决。Mac 界面行为及既有额度控制规则保持不变。

## Changes / 更新

- **One padding layer:** the shared Windows input template no longer adds the same padding again as an outer margin. / **消除重复边距：**Windows 输入框模板不再将同一内边距额外算作外边距。
- **Font-aware fields:** numeric inputs use a minimum height that accommodates their actual font metrics rather than a restrictive fixed height. / **按字体适配高度：**数值框使用能够容纳实际字体的最小高度，避免固定高度裁切。
- **Shared-control regression coverage:** checks include rule values, the search field, and multiline instructions so that the common template retains editing and scrolling behavior. / **共享控件回归：**覆盖规则数值、搜索和多行指令框，保留编辑与滚动行为。
- **Illustrated release notes:** six native previews cover both platforms and four page types. Windows Rules in Chinese/light and English/dark are the highlights; main windows, settings, and the Mac menu remain available in the gallery. / **附图发行说明：**六张原生预览覆盖两平台及四类页面，重点展示中英文、浅深色 Windows 规则页，并保留主窗、设置及 Mac 菜单。

## Validation and limits / 验证与限制

The Windows release gate compares the former and corrected templates in the same native WPF process. Its receipt checks text bounds against the visible viewport, verifies that the original clipping can be reproduced and the corrected fields remain readable, and checks that multiline scrolling is retained. Cases cover Chinese/English, light/dark appearance, logical layout scaling, and enlarged fonts. Package, lifecycle, and gallery checks remain separate gates. The attached receipts report the actual result; a failed or skipped check is not a pass.

Windows 发行检查在同一原生 WPF 进程中比较旧、新模板，核对文字边界与可视区域，确认能够复现旧裁切、修复后完整可见，并保留多行滚动。案例覆盖中英文、浅深色、逻辑布局缩放及增大字号。安装包、退出生命周期与图库仍分别验收，实际结果以附带回执为准，失败或跳过不计通过。

The layout-scale and font-size stress cases are synthetic checks. They do **not** switch the monitor DPI or Windows accessibility text-size settings. The `--scale` option used for preview PNGs controls bitmap output and is not proof of real 125%/150%/200% desktop-DPI coverage. Actual display-DPI and system text-size combinations, including moving between monitors, remain manual acceptance items. No system display or accessibility setting is changed by this test.

布局缩放及字号压力案例属于模拟检查，**不会切换显示器 DPI 或 Windows 辅助功能文字大小**。预览图的 `--scale` 只控制位图输出，不能证明已经验收真实桌面的 125%／150%／200% DPI。实际 DPI、系统文字大小组合及跨显示器移动仍需单独人工验收；测试不修改显示或辅助功能设置。

The screenshots use demo data and are not evidence of live-client quota control. Windows live pause/recovery, one-time scheduling, real keyboard/IME interaction, startup/notifications, and lock/display-off/sleep/lid behavior retain their existing acceptance limits. The Mac preview remains ad-hoc signed and unnotarized; Windows remains unsigned. Supported client profiles and other preview limitations continue to apply.

预览图使用示例数据，不作为真实客户端额度控制的验收证据。Windows 实际暂停续接、一次性预约、真人键盘及输入法、登录启动与通知，以及锁屏、熄屏、睡眠和合盖行为继续保留既有验收限制。Mac 仍为临时签名且未公证，Windows 仍未签名；客户端兼容范围及其他预览限制继续适用。
