# V0.3.0 public preview / 公开预览

Native Codex task management for macOS and Windows, with configurable operating rules, four accent themes, and clearer recovery records. Preview build tags use `v0.3.0-preview.N`; the associated release assets and receipts identify the exact build and source commit.

面向 Mac 和 Windows 的原生 Codex 任务管家，增加可配置运行规则、四种主题色和更准确的额度恢复记录。具体预览标签采用 `v0.3.0-preview.N`，准确构建及源码提交以所在发行页的文件和回执为准。

## Changes / 更新

- **Two-column task cards:** status beside the title, execution stage below, and automatic control at the top of the instruction area. Scheduling and Run now remain available. / **两列任务卡片：**状态放在标题旁，执行阶段位于下方，自动控制移至指令区顶部，保留预约和立刻执行。
- **Codex-focused interface:** chat list and controls present Codex tasks. / **Codex 专属界面：**聊天目录与控制入口统一聚焦 Codex。
- **Editable operating rules:** pause threshold 1–50% (default 10), resume threshold 5–95% (default 20), normal collection 10–300s (default 30), near-limit collection 5–60s (default 10), recovery confirmation 3–60s (default 5), and UI refresh 2–30s (default 5). Resume must exceed pause by at least 5 percentage points; near-limit collection cannot be slower than normal collection. Failed/conflicting saves retain drafts. / **可编辑运行规则：**六项参数具备范围、关联校验和保存冲突保护；官方额度及刷新时间仍为只读。
- **Four accents:** green, blue, purple, and egg yellow, each in light and dark appearance; system appearance and Chinese/English remain supported. / **四种主题色：**绿、蓝、紫、鹅蛋黄，均支持浅深色，并保留跟随系统及中英文。
- **Mac Chinese-input fix:** a native text editor protects marked text, selection, and unsaved instructions from background updates and appearance changes. / **Mac 中文输入修复：**原生编辑器保护中文组合输入、光标和未保存指令，避免后台刷新覆盖。
- **Early balance restoration:** eligible automatic resumptions and one-time schedules can proceed after repeated fresh balance verification even when the reported reset time has not advanced. Existing authorization, account, manual-hold, and delivery checks remain in force. / **提前恢复续接：**连续重新核验余额恢复后，即使刷新时间没有前进，也可继续符合条件的受管任务和一次性预约；保留既有授权、账号、人工保持与送达检查。
- **Truthful recovery records:** distinguish a new quota window, verified balance recovery, and restored service permission. A balance increase alone does not prove an official reset; unknown causes remain unknown. / **恢复记录更准确：**区分新窗口、余额恢复及服务许可恢复，不将未知原因描述为官方重置。
- **Read-only reset credits:** show service-provided counts and details when available; never redeem automatically or treat unused credits as recovered quota. / **重置权益只读展示：**按服务数据展示数量和详情，不自动兑换、不将未使用权益视为额度恢复。
- **Unified delivery:** both platforms read the central version and bundle their backend and pinned Python runtime. / **统一交付：**两平台读取中央版本，随包提供后端与固定 Python 运行环境。

## Packages / 安装包

- **Mac:** `Codex-Mission-Manager-0.3.0-arm64-preview.dmg` — Apple Silicon, macOS 14 or later. / Apple Silicon、macOS 14 或更新版本。
- **Windows setup:** `Codex-Mission-Manager-0.3.0-windows-x64-setup.exe` — current-user installation, Windows 10 build 19041 or later, x64, .NET Framework 4.8 or later. / 当前用户安装，需 Windows 10 build 19041 或更新版本、x64、.NET Framework 4.8 或更新版本。
- **Windows portable:** `Codex-Mission-Manager-0.3.0-windows-x64-preview.zip` — extract to a dedicated folder before opening the EXE. / 解压到专用目录后运行。

Install a compatible official Codex desktop client and sign in separately. Quit Mission Manager before upgrading. Existing local data is retained; fresh installations start with global automatic control paused. See the [user guide](https://github.com/Dddysun/Codex-Mission-Manager/blob/main/docs/USER_GUIDE.md).

需另行安装并登录兼容的官方 Codex 桌面客户端。更新前退出管家，既有本机数据保留；新安装默认暂停全局自动控制。详见 [使用指南](https://github.com/Dddysun/Codex-Mission-Manager/blob/main/docs/USER_GUIDE.md)。

## Validation scope / 验证范围

Mac implementation checks include native compilation, control/rules contracts, four-accent light/dark fixture rendering plus settings/rules/menu pages, and a programmatic check using actual native marked-text composition. The editor check verifies composition, selection, and draft preservation without a backend or live messages. It does not reproduce an interactive keyboard candidate window.

Mac 实现已完成原生编译、控制与规则契约检查、四主题浅深色及设置／规则／菜单的示例渲染，并通过真实原生编辑器的程序化组合文本检查。该检查验证组合输入、光标和草稿保留，不启动后台、不发送消息；不等于真实键盘候选窗验收。

The unified release workflow repeats isolated Mac checks and package verification. Windows coverage is limited to build/runtime/installer checks, platform/host smoke tests, native editor and window-lifecycle checks, and synthetic UI renders. Full Windows backend acceptance and live-client control are not established by this coverage. Read the attached receipts for the result and scope of each preview; skipped checks are not passes.

统一发行工作流重复执行 Mac 隔离检查及安装包验证。Windows 验证仅覆盖构建／运行环境／安装器、平台与宿主冒烟测试、原生编辑器及窗口生命周期、示例界面渲染，不代表已完成完整 Windows 后端验收或真实客户端控制验收。每个预览的实际结果以附带回执为准，跳过不计为通过。

## Remaining manual checks / 待人工验收

Interactive checks requiring an unlocked Mac and checks against the installed application were not performed for this preview. The following remain separate manual acceptance items on the relevant platform:

- Real Chinese keyboard composition while polling, sorting, changing language/appearance, and moving the caret on Mac.
- Clean installation, upgrade, login startup, notification delivery, and real menu-bar/system-tray reopen.
- Live Run now delivery, quota-triggered pause and verified recovery, and one-time schedules, including account changes, approval/input waits, manual holds, and uncertain-send handling.
- Display-off, locked-screen, sleep/wake, and lid-closed operation under actual system power settings.
- Windows text entry and layout at 125%, 150%, and 200% display scaling; full end-to-end acceptance against the exact supported client version.

本次未执行需要解锁 Mac 的交互检查或已安装应用检查。相关平台仍需分别验收：真实中文键盘输入及候选窗；首次安装、升级、登录启动、通知和菜单栏／托盘重开；真实即时发送、额度暂停续接和一次性预约及人工接管边界；熄屏、锁屏、睡眠唤醒及合盖；准确客户端版本下的完整 Windows 端到端流程。

## Known limits / 已知限制

The Mac preview is ad-hoc signed and not notarized; Windows is unsigned. Operating systems may block opening the packages. The Mac closed-lid helper is unavailable, and neither platform guarantees operation with the lid closed and no external display. Intel Mac, Windows ARM, simultaneous multi-account operation, and automatic updates are not provided.

Mac 预览采用临时签名且未公证，Windows 预览未签名，系统可能阻止打开。Mac 合盖辅助服务暂不可用，两平台均不保证无外屏合盖运行。尚不支持 Intel Mac、Windows ARM、多账号同时运行或自动更新。

Control depends on a version-sensitive local client adapter. The source currently contains Mac build profiles 20770 and 21828, and Windows package profile 26.1021.3705.0. An unknown version blocks control. Profile matching and read-only snapshots are compatibility evidence, not proof of live pause/resume acceptance. Quota limits and reset times come from the service and cannot be changed by Mission Manager.

控制依赖版本敏感的本机客户端适配。当前源码包含 Mac build 20770、21828 和 Windows 包版本 26.1021.3705.0 的兼容配置，未知版本停止控制。配置匹配及只读快照只能证明相应兼容性，不能代替真实暂停／续接验收。官方额度与刷新时间由服务决定，管家不能修改。
