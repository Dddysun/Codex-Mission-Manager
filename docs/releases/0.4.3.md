# V0.4.3 — Monitoring window and collection status / 监控窗口与采集状态

## 更新 / Changes

运行规则新增“五小时额度／周额度”。Plus 可选实际可用的窗口；Pro 默认周额度且五小时置灰。首次使用与旧设置自动适配。选定窗口使用暂停／恢复阈值，默认 10%／20%；其他窗口用尽及服务禁止使用仍会暂停。缺失、过期、非法的窗口选择会被拒绝，显式选择失效后暂缓自动续接。

Operating rules now offer five-hour or weekly monitoring. Plus can choose available windows; Pro defaults to weekly with five-hour disabled. New and legacy settings adapt automatically. The selected window uses the pause/resume thresholds, 10%/20% by default. Other exhausted windows and service blocks still pause eligible tasks. Missing, stale and invalid selections are rejected; unavailable explicit selections withhold automatic resumption.

选择与六项数值规则一起保存，使用同一版本冲突保护。保存不会开启全局榨汁或解除手动保持；采集中发生规则变化时，旧轮次不能继续执行控制。新预约使用所选窗口，已有预约保留原窗口。

Window choice and the six numeric rules save atomically under one revision. Saving does not enable global juicing or clear manual holds. A rule change during collection cancels control from the old cycle. New schedules follow the selected window; existing schedules retain their original window.

每轮额度读完并核验后先更新缓存，再采集聊天。额度时间戳取实际读取时间，不再取整轮开始时间；真正过期仍会停止自动续接。目录发现结果每轮复用。恢复复核等待会影响下轮间隔，但处理耗时另计，不保证恰好在设置秒数续接。

Fresh verified quota is published before chat collection, using its actual observation time rather than cycle start. Truly stale data still blocks automatic resumption. Discovery results are reused within the cycle. Confirmation deadlines shorten the next collection delay; processing time remains additional.

例行检查不关闭全局榨汁，也不因核验提示主动中断当前聊天。Windows 新增选项文字跟随深浅色主题，并检查深色对比度。Mac、Windows 使用更明确的重试说明；Windows 区分“待核验”和“已停止”。采集中且状态有效时 Logo 保持工作状态。

Routine checks do not disable global juicing or interrupt a chat solely because verification is pending. New Windows option labels follow the light/dark theme and check dark-mode contrast. Both native interfaces explain retries; Windows distinguishes Awaiting verification from Stopped. Valid state keeps the working logo during collection.

## 验证边界 / Verification limits

新增离线测试覆盖周额度 0、1、10、11、19、20% 边界、其他窗口用尽、Pro 可选项、过期／未来采样、规则版本竞争、预约窗口保留、采集中状态发布，以及重复暂停／续接保护。界面预览使用模拟数据，不发送消息或中断真实聊天。

New isolated checks cover weekly boundaries at 0, 1, 10, 11, 19 and 20%, exhaustion of other windows, Pro choices, stale/future samples, rule-revision races, preserved schedule anchors, early publication during collection, and duplicate-action protection. Native previews use synthetic data and send no messages or interruptions to real chats.

旧版短时只读观察未复现间歇提示；修复针对已确认的时间戳和发布时序隐患，不能声称已重现全部原因。真实低额度暂停至恢复续接、设备安装与托盘交互仍需分别记录实机验收。

A short read-only observation of the previous build did not reproduce the intermittent warning. These changes address confirmed timestamp and publication-order weaknesses, not a proven explanation of every occurrence. Live quota recovery, installation and tray interactions require separate acceptance evidence.

Mac 预览仍为临时签名、未公证；Windows 预览未签名。品牌组件保持 1.3.0，保留十种内核放电和 2 秒呼吸。控制依赖版本适配的本机通信；未知状态不发送，结果不确定不重发。已有数据目录保留，不包含私人运行数据。

Mac previews remain ad-hoc signed and unnotarized; Windows previews remain unsigned. Brand 1.3.0 retains ten core discharges and two-second breathing. Control depends on a version-adapted local channel; unknown state blocks sending and uncertain delivery is not replayed. Existing data locations are retained; packages contain no private runtime data.
