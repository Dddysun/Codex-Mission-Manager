# V0.3.1 public preview / 公开预览

A reliability update for quitting Mission Manager on Mac and Windows. Includes all [V0.3.0 features](https://github.com/Dddysun/Codex-Mission-Manager/blob/main/docs/releases/0.3.0.md).

本次更新改进 Mac 与 Windows 的完整退出流程，并包含 V0.3.0 的规则设置、四种主题、任务卡片布局及额度恢复功能。

## Changes / 更新

- **Visible Quit:** the Mac menu panel keeps **Quit Mission Manager** in a fixed footer. The application menu and ⌘Q provide the same action. Windows retains an explicit tray Quit action. / **明确的退出入口：**Mac 菜单面板底部固定显示“退出任务管家”，应用菜单与 ⌘Q 使用同一流程；Windows 保留明确的托盘退出入口。
- **Bounded, repeat-safe shutdown:** stop requests, process waits, and cleanup run outside the UI thread with deadlines. Repeated requests reuse the same shutdown operation. / **有时限、可重复点击的退出：**后台停止、进程等待与清理避免阻塞界面，并设置截止时间；重复退出不会重复启动清理。
- **Owned-process cleanup:** cleanup targets the application's own background process family, including stalled helper processes. Existing client tasks receive no interrupt or resume command on quit. Attached external legacy services are detached rather than terminated. / **仅清理自身进程：**回收应用自身的后台及其子进程，不向原客户端任务发送暂停或续接命令；对于接入的外部旧服务仅断开连接。
- **Close-to-background remains available:** closing the main window continues menu-bar/tray operation. Full exit uses Quit. / **保留关窗驻后台：**关闭主窗口后继续在菜单栏／托盘运行，完整退出使用“退出”。
- **Consistent Windows version labels:** installed-app registration and installation receipts use the actual preview build number. / **Windows 版本标识一致：**系统已安装应用及安装回执显示实际预览构建号。
- **No new system permissions:** quitting does not request Accessibility, screen recording, administrator access, or changes to system protection. / **不增加系统授权：**退出无需辅助功能、录屏或管理员权限，不修改系统保护设置。

## Packages and upgrade / 安装包与升级

Choose the V0.3.1 preview from [Releases](https://github.com/Dddysun/Codex-Mission-Manager/releases). Each immutable `v0.3.1-preview.N` tag identifies its own source commit and files:

- `Codex-Mission-Manager-0.3.1-arm64-preview.dmg` — Apple Silicon, macOS 14+.
- `Codex-Mission-Manager-0.3.1-windows-x64-setup.exe` — current-user install, Windows 10 build 19041+, x64, .NET Framework 4.8+.
- `Codex-Mission-Manager-0.3.1-windows-x64-preview.zip` — portable Windows package.

Both packages bundle the backend and pinned Python runtime. Quit the old version, wait for it to exit, then install the update. Existing configuration, records, and schedules remain in the application-data directory. See the [user guide](https://github.com/Dddysun/Codex-Mission-Manager/blob/main/docs/USER_GUIDE.md).

两平台均附带后端和固定 Python 环境。升级前从应用菜单或托盘退出旧版，等待进程结束后再安装；用户配置、记录与预约保存在独立应用数据目录。预览包的系统要求及使用说明见使用指南。

## Validation and remaining checks / 验证与待验收

The release is gated on both platform builds. Attached receipts describe the actual result and scope: isolated backend/host tests, synthetic shutdown fault cases, native lifecycle checks, fixture UI renders, package/runtime checks, and checksums. Synthetic checks do not establish live-client pause/resume delivery or interactive input acceptance. Skipped checks are not passes.

发行需通过两平台构建。附带回执说明实际测试范围与结果：隔离后台／宿主测试、模拟退出异常、原生生命周期、示例界面、安装包与运行环境检查及校验摘要。模拟测试不能替代真实客户端暂停续接或真人输入验收，跳过不计为通过。

Manual acceptance remains necessary for installation/upgrade on other machines, real tray/menu-bar interaction, startup/notification behavior, Chinese input candidates under refresh, Windows 125%/150%/200% scaling, and live quota pause/recovery/schedules. Lock, display-off, sleep/wake, and lid-closed behavior depend on the actual system environment and remain separate checks.

其他机器的安装升级、真实菜单栏／托盘、登录启动与通知、刷新期间的中文候选输入、Windows 缩放以及实际额度暂停／恢复／预约，仍需人工验收。锁屏、熄屏、睡眠唤醒与合盖行为取决于实际系统环境，单独验收。需要解锁才能执行的检查可以后续补做。

## Preview limits / 预览限制

Mac packages remain ad-hoc signed and not Apple-notarized; Windows packages are unsigned. No closed-lid operation guarantee or new privileged service is introduced. Supported client profiles and other V0.3.0 limitations still apply. Quitting stops Mission Manager's automation; it does not cancel work already running in the official client.

Mac 仍为临时签名、未公证的预览包，Windows 仍未签名。本次不新增管理员服务，也不保证无外屏合盖运行。客户端兼容配置及 V0.3.0 的其他限制继续适用。退出会停止管家的自动控制，原客户端已在运行的任务继续保留。
