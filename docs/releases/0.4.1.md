# V0.4.1 — TOKEN榨汁机 / TokenMax

## 本次更新

- 中文应用名改为 **TOKEN榨汁机**，同步窗口、菜单、通知和安装入口；英文保留 **TokenMax**。
- Mac 菜单栏使用独立的彩色小图标，改善深色背景下的辨识度。
- 杯内闪电下移，留出杯盖间距。工作状态使用金色呼吸闪电、分叉电流、暖色亮芯和流动拖尾。
- 深色模式降低整体亮度；系统“减少动态效果”开启时停止循环动画。等待、断连和错误仍以杯内符号区分。
- Mac、Windows 和独立 SVG 组件同步更新。任务控制逻辑、已有配置与记录保持兼容。

- 修复长会话状态超过 64 MiB 后全局状态同步中断的问题；接收容量调整为有界的 128 MiB，并补充 Mac 自动重连和连接失败提示。

## What's new

- Updated the Chinese app name to **TOKEN榨汁机** across windows, menus, notifications and installation entries. The English name remains **TokenMax**.
- A dedicated full-color Mac menu-bar icon improves readability at small sizes.
- Lowered the bolt inside the cup. Working mode combines a breathing gold bolt with branching electric trails and a warm luminous core.
- Subdued dark colors and system reduced-motion support remain available. Waiting, disconnected and error symbols stay inside the cup.
- Updated both native apps and the reusable SVG component. Task control behavior, settings and history remain compatible.

- Fixed status synchronization stopping on conversation snapshots larger than 64 MiB. The bounded limit is now 128 MiB, with Mac reconnection and accurate connection-failure reporting.

## 安装与升级 / Install and upgrade

- `TokenMax-0.4.1-arm64-preview.dmg` — Apple Silicon / macOS 14+.
- `TokenMax-0.4.1-windows-x64-setup.exe` — Windows 10 build 19041+ / x64 / .NET Framework 4.8+.
- `TokenMax-0.4.1-windows-x64-preview.zip` — Windows portable package.

退出旧版后安装。Mac 替换 `TokenMax.app`；Windows 使用安装程序升级。配置、任务和操作记录保留。旧名快捷方式只在目标匹配本应用时迁移。

Quit the previous version before installing. Replace `TokenMax.app` on Mac or run the Windows installer. Settings, tasks and activity are retained. Legacy shortcuts migrate only when their target matches this application.

## 验证范围 / Validation

发布要求两平台构建、原生离线检查和同版本示例截图通过；实际结果见附带测试回执。截图使用模拟数据。Windows 完整实机验收与真实额度暂停／续接仍需人工测试。

Publication requires both platform builds, native offline checks and same-version fixture screenshots. Attached receipts report the results. Full Windows hands-on acceptance and live quota pause/resume remain manual checks.

Mac 预览为临时签名、未公证；Windows 预览未签名。客户端兼容性和合盖辅助服务限制继续适用。

The Mac preview is ad-hoc signed and unnotarized; Windows is unsigned. Existing client compatibility and closed-lid helper limitations still apply.
