# Windows 与 Mac 原生界面还原

本轮 Windows 内容界面以当前 Mac 原生应用为参考重新实现，使用 WPF，不使用 WebView。对照采用同一份 `native-state.json` 示例数据，主界面逻辑尺寸 1380×900，均以 2 倍像素渲染；设置内容 800×1100，托盘面板 400×570。

## 对齐内容

- 深绿侧栏、盾牌品牌、导航图标与选中态、额度进度条、固定底部账号/设置入口。
- 面包屑、刷新按钮、页面标题与说明、四项统计、来源分段选择、状态筛选和搜索。
- 三列聊天卡：聊天与执行阶段、状态与自动控制、一次性预约与指令框；保留当前 Mac 的预约窗口说明。
- 相邻标签和开关、状态徽章、圆角输入与按钮、主题适配的下拉菜单和细滚动条。
- 独立设置窗口、六组运行规则、操作记录和原生托盘面板。
- 中英文、跟随系统/浅色/深色。语言名称始终为“简体中文 / English”，避免翻译后的长名称被裁切。

浅色主背景为 `#ECECEC`，表面为白色；深色主背景为 `#323232`，表面为 `#1E1E1E`。侧栏及选中态分别为浅色 `#192822 / #35423D`、深色 `#0D1712 / #2A332F`。品牌图标来自项目现有 Mac 图标资产，而非 Windows 系统 UAC 图标。

Windows 保留自己的标题栏、窗口按钮、系统字体和文字渲染，没有复制 Mac 红黄绿按钮或分发 Apple 字体。权限功能按 Windows 真实能力显示；视觉对齐不表示 Windows 具有 Mac 特权辅助服务。

## 比对与验收

第三轮主窗口截图的独立只读比对已通过，无文本重叠、主控件截断或深色控件白底残留。按逻辑像素测量：

- 统计卡：Mac Y154–231，Windows Y155–231。
- 前两项任务卡：Mac Y321–527、540–746；Windows Y322–528、542–748。
- 前两项阶段卡：Mac Y381–459、600–678；Windows Y381–458、601–677。
- 三列宽度与相邻开关关系已对齐。第三行按相同视口被裁切并可滚动，这是参考应用本身的行为。

随后冻结版本补齐语言选项、六组规则、只读发送回执和后台隐藏启动时的辅助窗口归属处理。最终 EXE 仍须通过完整编译、自检和页面渲染，具体证据见本轮 Windows 界面验收记录。

所有公开预览只含示例聊天、示例账号和示例额度。日期按各系统本地时区显示；对照时不把系统时区导致的显示时间差当作布局差异。真实账号、聊天和桌面截图不进入仓库。

## 离线复验

```powershell
.\CodexMissionManager.exe --ui-self-test fixture.json preview.png --view home --language zh --theme light --scale 2
```

`view` 支持 `home`、`settings`、`activity`、`rules`、`tray`。离线渲染不启动后台、不读取私人偏好、不连接真实客户端，也不发送任务；不能用渲染成功代替真实暂停/续接验收。
