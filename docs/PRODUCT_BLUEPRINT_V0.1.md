# Codex Mission Manager / 任务管家 — 产品总蓝图（V0.2 修订）

状态：V0.1 基线建立于 2026-10-23，V0.2 修订确认于 2026-10-24，Asia/Dubai。后续产品、代码、打包与验收以本文件为基线。修订后的规则优先于历史设定；实现或验证缺口单列，不得改写为已完成。文件名保留以维持既有引用。

## 1. 产品目标

Mac 本机的聊天任务管家：在额度不足时暂停工作，额度可靠恢复后继续原聊天；支持用户安排下一额度窗口的一次性指令，以及即时发送指令。额度监测为内部调度提供依据，不另做独立用量产品。

## 2. 交付形态与菜单栏

- 原生 Mac 应用，DMG 内拖入 Applications 安装。
- 应用包含前端、后端及 Python 运行环境；日常使用不要求安装 Python、Node、Homebrew 或打开终端。
- 主窗口使用 SwiftUI / AppKit 原生控件实现聊天列表、当前执行阶段、控制开关、指令框、操作记录、账号与额度侧栏；不以 WKWebView 嵌入网页作为应用主界面。原有 Python 后台通过本机 JSON 接口提供数据和控制。
- 菜单栏仍为固定 Logo；左键或右键均打开原生控制面板。图标不绑定单个聊天的状态，不显示动态状态色。
- 面板展示当前账号实际返回的订阅类型、五小时额度、周额度与刷新时间，并标明缺失或过期状态。
- 额度下方并列提供暂停/恢复全局自动控制与“暂停所有任务”。其余入口为打开主窗口、设置、语言、外观和退出。
- 本轮规则明确取代 V0.1 的“菜单栏不展示额度、只提供三个入口”设定；不要求将完整聊天目录放入菜单栏。
- 关闭窗口：后台继续工作。退出应用：停止管家后台及其防睡眠保护；不主动中断原客户端正在执行的聊天。

## 3. 聊天、账号和额度

- 目录区分本机 Codex 与 ChatGPT。遵从用户选择，ChatGPT 普通聊天仅显示目录，不自动执行。
- 目录必须说明覆盖范围和更新时间，不将近期快照标为全账号历史。
- 每个聊天显示名称、来源、当前运行状态、最近公开执行进展及可用时间；新回合无进展时不复用旧结果。不展示隐藏推理、用户原文或工具日志。
- 自动控制开关位于当前状态下方。当前回合完成后为等待指令，不自动无限续做。
- 侧栏展示五小时、周额度的实际余量和刷新时间，以及头像/姓名首字母、账号 ID、实际 Free/Plus/Pro 等订阅类型。
- 未返回的限额显示未提供，过期数据标记上次记录；不能将 Pro 硬编码为无限额度。
- 当前登录账号发生变化时停止旧账号的自动提交并要求重新核验。未来支持多账号；V0.1 不承诺多账号同时登录。

## 4. 三条独立控制路径

### 自动控制

- 默认低额度阈值为五小时剩余 ≤10%；周额度或服务不可用也阻止自动续做。
- 仅对允许接管、且未等待人工审批/输入的执行中聊天进行可确认的暂停。
- 确认真正恢复窗口、五小时至少20%、周额度和服务许可可用、账号及原聊天进度匹配，连续复核后续做。
- 关闭单聊自动控制不等于停止该聊天，也不取消独立预约。
- 全局暂停自动控制阻止自动暂停、自动续接和预约发送；明确点击的手动即时发送独立处理。
- 全局暂停期间，单聊接管请求显示“等待全局启用”，不显示为正在连接；用户可以取消。启用全局自动控制后才开始处理接管请求。
- 连接失败显示明确原因并允许重试。同一聊天的待处理接管请求去重，取消后不在后台继续接管。

### 下个窗口执行一次

- 用户可为原本空闲、或并非由额度中断的聊天安排执行。
- 指令默认“继续任务”，可修改，开关与自动控制独立。
- 只有下一五小时窗口真实恢复且额度/账号/服务条件满足时才发送一次；确认后预约关闭。
- 允许修改和取消；新人工指令、审批、Goal、账号变化优先复核。

### 立刻执行

- 按钮在保存/预约按钮右侧，发送当前输入框草稿，不等待额度刷新。
- 只向空闲且可核验的本机 Codex 聊天发送；不打断执行中任务、不绕过审批。
- 显示待发送、检查中、确认中、已确认发送、未发送、结果待核对，以及发送标识和已确认回合 ID。
- 独立保留未来预约的内容和目标窗口。
- 唯一发送标识、持久化意图与重启核对避免重复；结果不明确时不重发。即时请求过期后不在未来悄悄执行。

### 手动暂停受管任务

- 菜单栏“暂停所有任务”只作用于已授权自动控制的受管聊天，需逐项核对当前执行状态。
- 未授权、空闲、等待审批或等待用户输入的聊天跳过；不以任务目录中的全部聊天推断暂停许可。
- 提交后关闭全局自动控制，逐项显示已确认暂停、跳过和需处理结果。
- 确认暂停的任务保留手动保持状态；之后恢复全局自动控制不会隐式恢复这些任务。
- 请求先持久化；崩溃或提交结果不确定时不自动重复中断。账号或原回合变化时停止该项操作。

## 5. 后台运行场景

1. 正常开盖：用户使用其他应用时持续后台工作，不抢前台。
2. 锁屏：保持登录会话、系统清醒、客户端与网络可用；单独验收锁屏发送及未加载聊天的打开能力。
3. 熄屏：允许屏幕关闭，通过电源断言保持系统运行。
4. 合盖：完整产品目标要求支持无外接显示器的合盖运行，并维持锁定状态；当前公开试用版本尚未开放，不计为已交付能力。

合盖是独立、默认关闭的增强开关；建议默认仅接电启用。通过受限管理员辅助服务控制睡眠覆盖。用户主动开启后才申请系统授权，不借用普通防空闲睡眠来宣称合盖可用。

停用、退出、后台失联时恢复本应用接管前的睡眠配置；不使用全局恢复默认设置覆盖用户其他电源偏好。低电量或系统严重热压力时撤销合盖保持，并保留调度记录。与其他电源工具的冲突要显示原因。

## 6. 设置：后台运行与系统权限

每项采用统一横向布局：图标与用途说明、真实状态、左右滑块、系统设置按钮。滑块左侧为关闭、右侧为开启。新安装默认关闭可选开关；升级保留用户已有偏好。未知状态与不可用状态不伪装为已授权。

设置按系统实际能力执行申请、撤销或跳转。需要系统批准的操作在状态确认前不显示已开启。禁用功能仍提供简短原因和适用的系统设置入口。

- 登录启动和后台服务：系统服务登记及用户许可，区分未注册、待批准、已允许、不可用。
- 普通防睡眠：应用电源状态，不是独立隐私权限；显示断言是否生效。
- 无外屏合盖：管理员辅助服务授权、服务连接、实际睡眠标志和实机验收分别展示。
- 通知：区分应用通知偏好与系统授权。滑块关闭只停止应用发送，不声称撤销 macOS 通知权限；系统已拒绝时引导到通知设置。拒绝通知不阻止后台任务。
- 客户端与账号：应用存在、兼容版本、通信及登录态检测；不将“连接成功”混作系统授权。
- 不为当前通信方式预先索取辅助功能、录屏或完全磁盘访问权限。实际所需文件访问问题必须具体说明。
- 不能可靠检测时显示待确认，不用假绿灯代替检查。

## 7. 通知、记录与数据

通知只用于暂停、续接、发送失败及需要处理的异常；未变化的轮询不通知。每次控制保留本机操作记录。账号、聊天、令牌及账本不上传 GitHub；仓库只存应用代码、文档、构建配置和脱敏验证结果。

## 8. 依赖与兼容边界

当前执行依赖原 ChatGPT/Codex 桌面客户端和登录会话，不是另一个独立 Agent 执行器。现有桌面控制属于版本敏感的本机兼容通道。

- 前后端使用同一兼容配置，不在设置页单独写死版本结论。
- 启动和每次控制前检查当前客户端版本；未知版本停止控制并提示应用更新。
- 连接正常、只读协议正常、写入协议测试与真实控制验收分别记录，不以某一项成功代替其他项。
- V0.2 兼容配置覆盖 build 20770 与 21828；21828 的本机只读验证已完成，真实暂停和发送验证仍须单列。

应用运行时可自带；原客户端不随 DMG 分发。正式管理员辅助服务需要可信应用身份与客户端校验。缺少发行签名时，预览包必须标明限制，不能绕过系统验证或伪造已授权状态。

## 9. 验收

- DMG 可验证、挂载；应用包含可运行后端及前端，离开开发目录不依赖系统 Python。
- 窗口关闭后后台继续，退出后自身进程和电源保持释放。
- 聊天目录、阶段、状态、账号、额度按真实数据展示；后台未连接时显示可操作的原因。
- 即时指令真实到达、取得回执；预约与自动续接不重复发送。
- 锁屏、熄屏和无外屏合盖分别实机验收，尤其是窗口恢复后的实际发送。
- 授权拒绝、缺少客户端、版本不符、断网、崩溃及重启都保留清楚状态和可恢复记录。
- 发行签名、公证、管理员授权和实机合盖测试未完成时，在发行说明中逐项标记，不宣称完整通过。

## 11. 原生窗口修订（2026-10-23）

用户明确要求真正的 macOS 程序窗口。原先内嵌网页的预览包不满足此项；后续主界面、设置和交互均使用 SwiftUI / AppKit，保留系统文本编辑、菜单与可访问性支持。网页仅为旧服务兼容入口，不承担新应用界面渲染。

## 12. V0.2 外观、语言与公开文案（2026-10-24）

- 默认跟随 macOS 外观，并提供浅色和深色选项；主窗口、设置、菜单栏面板与状态控件一并适配。
- 简体中文与 English 可在菜单栏或设置中即时切换，保存选择，不要求重启。系统菜单、按钮、状态和帮助文本纳入本地化；用户聊天名称、输入指令和原始内容保持原文。
- 权限滑块、语言、外观与当前账号用量在各窗口保持一致。
- 前端文案面向公开试用用户，使用简洁、正式、可操作的产品语言。移除助手对话口吻、面向单一用户的说明和开发过程记录。
- 兼容、权限拒绝、功能不可用与发送未确认等会影响使用的事实仍明确展示，并提供重试、更新或系统设置等适用操作；不在普通设置页堆放内部验收过程。
- V0.2 发布前检查中英文、浅色/深色及跟随系统、权限拒绝/未知、菜单栏左/右键、接管等待/取消/失败、手动暂停结果与重启不重放。测试结果以发行记录为准。
