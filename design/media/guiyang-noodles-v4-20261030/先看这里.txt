技术与使用
1080×1920，30 fps，H.264，无音轨。沿用用户要求的白底及代码逐帧动画。
源码在 src/scene.js，可调时间线与排布；公共 SVG 绘制函数在 src/draw.js。
运行需要 Node.js、Playwright 1.62.1、Chromium 与 FFmpeg。系统需有中文字体。
  npm install
  npx playwright install chromium --only-shell
  npm run render
浏览器预览：本目录执行 python3 -m http.server 8765，然后打开 http://localhost:8765。
src/package.py 负责分拆与核验视频、提取终帧、替换总串片和打包。
重建总串片需要旁边保留 motion-v3-20261030 原目录；不影响本段独立渲染。

素材性质
面摊、牛肉面与加料都是代码绘制的动画插画，没有声称是实际店铺或实拍。
20 元沿用用户提供的口播情境。
地理数据沿用前次已采集的 China-GeoData 与 OpenStreetMap 数据，非重新查询的实时地图。
地图画面保留来源标注；本包附对应许可证。
没有调用 Opus，没有生成旁白，也没有改动其余镜头内容。
